# Texas Quantitative — Simple Static Site (No Build Tools)

This is a zero-build static site using **Tailwind CDN**. Drop these files into your repo root and enable **GitHub Pages (Deploy from branch)**.

## Deploy steps
1. Copy all files to your repository root.
2. Commit and push.
3. Repo Settings → Pages → *Deploy from branch* (main / root).
4. Ensure `CNAME` contains `txqai.com`, add DNS A-records to GitHub Pages IPs, and enable **Enforce HTTPS**.
